 كيت 35 [cj-pid-guard] — جرد صحي روابط CJ + جرد الريفيوزات
 LaClarc · 2026-10-22

⚠️ ماشي كيت إصلاح — الكاطالوج تاعك صحي 100% (جرد 2026-10-22:
   24 منتج · 21 pid رقمي + 3 pid UUID · صفر صيغ غريبة · صفر pid ميت).
   هادي أداة حارس: التشخيص المستقبلي فدقيقة، بلا ما تعاود القصة.

── القصة: جوج دروس موثقين (عمرهم ما تنعاو) ──

1) pids بصيغة UUID = صيغة رسمية جديدة تاع CJ 🡒 كاطالوج ES الجديد.
   CJ عندها جوج صيغ: رقمية 15-20 خانة (القديمة) + UUID 8-4-4-4-12 (الجديدة).
   الاستيراد خزّن صح. المنتجات 85347 / 51151 / 37043 أحياء ومتحقق منهم
   بـ product/query 200 + العنوان مطابق حرفياً. ما تحيدش UUID بالقوة!
   والريفيوزات خدّامة مع UUID: مثال مجرب 523508AB-… رجّع 648 ريفيوز.

2) البريدج /api/cj-live/search كيتيقبل ?q= ماشي ?keyWord=
   (keyWord هو الباراميتر الداخلي تاع CJ). إلا صيفطت keyWord= يرجع
   {geo:{},products:[],hasMore:false} بلا ما يضرب CJ — فخ تسمية، ماشي عطب.
   مثال صحيح: /api/cj-live/search?q=leather+belt&page=1&country=MA
   (country=MA = override → كاطالوغ عالمي، المغرب بلا مخزن CJ).

── الاستعمال ──
  CHECK-CJ-PID-HEALTH.bat                          جرد خفيف (موصى به)
  python verify_cj_pid_health.py                   نفس الشي من الطرفية
  python verify_cj_pid_health.py --deep            + فحص الحياة (≈20pt/منتج)
  python verify_cj_pid_health.py --deep --yes      بلا سؤال تأكيد
  python verify_cj_pid_health.py --json health.json  النتيجة فـ JSON
  python verify_cj_pid_health.py --base https://…  باك آخر

── اقتصاد النقاط ──
  · الجرد الخفيف: /reviews مكاشية 6h فالبريدج ≈ مجاني (24 نداء).
  · --deep: product/query + freight ≈ 20pt لكل منتج مربوط (24 ≈ 480pt).
  · البحث: 50pt على MISS (الكاش 5 دقايق) — ما تجربش بزاف كلمات.

── إلا لقيت pid ميت فـ --deep ──
  المنتج المحيّد من CJ: الـ PDP كتبقى خدّامة (ثمن مخزون + estimate)
  بصح بلا ثمن حي وبلا ريفيوزات، وكل زيارة كتحرق 20pt على نداء ميت.
  الإصلاح (يدوي مقصود — قرار تجاري):
    UPDATE products SET cj_product_id = NULL WHERE id = <المعرّف>;
  ولا أعد الاستيراد بمنتج بديل من CJ.

── الأمان ──
  الأداة قراءة فقط: ما كتبت في الداتابيز، ما بدلت كود، ما كاينش تراجع.
